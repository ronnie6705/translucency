# Task design assets

SVGs are unmodified exports from the user's supplied Figma files. They are stored locally because Figma MCP asset URLs expire. Space icons use alpha masks to preserve the exported geometry and opacity while applying the user's colour.

- Add Task: https://www.figma.com/design/5p3I8umBvC7GWpFURvr6nW/RMIT-Rhythm?node-id=1686-4509
- Task row: https://www.figma.com/design/5p3I8umBvC7GWpFURvr6nW/RMIT-Rhythm?node-id=1694-6276
- Anron Icons 10, Variants: https://www.figma.com/design/0iFSC99YzODvHJPCzRKyO8/Anron-Icons-10?node-id=2553-8397

The `add-*` and `row-*` files are exported from their respective frames. Home and Work use the Home 3 and Briefcase assets already placed in the authoritative Add Task design.
