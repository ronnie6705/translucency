# V1 implementation plan

North star: The app should help the user understand themselves without teaching them to monitor themselves more.

1. Typed local data model, IndexedDB transactions, separate sample records and deterministic insights.
2. Restrained material design: warm chalk #F6F5F1, ink #303D3A, sage #DFE7DF, water #E3EAF0, violet #E5E1ED, peach #EEE1D5. Georgia display, system sans body, monospace utility captions. The signature is one intact, luminous resin slab; supporting surfaces stay matte.
3. Desktop sidebar and asymmetric panel/context dashboard; mobile bottom navigation and stacked source sections.
4. Onboarding, check-in, source library, six default and custom roles, saved reappraisal and later reflection.
5. Calendar material history, deterministic patterns, preferences, export and deletion.
6. Manifest, icons, production offline cache, responsive and reduced-motion support.
7. Type/build tests, insight tests, browser flow verification and desktop/mobile visual review; README.

State is always selected by the person; sources never compute a health score. No diagnosis, notifications about symptoms, streaks or LLM dependency. Demo entries are explicitly labelled, removable independently, and never determine a person's current state.
